**Research · Projects · Accessibility · Static site**

| Layer | Files / tools |
| --- | --- |
| Content | `index.html`, `assets/`, `404.html` |
| Style | `main.css`, system fonts, light/dark themes |
| Navigation | `script.js`, hash routes, keyboard controls |
