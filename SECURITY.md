# Security and privacy

The portfolio is a static site hosted on GitHub Pages. Its code has no forms or analytics and does not set cookies. It saves the selected light or dark theme in the browser's `localStorage` under the key `theme`. If storage is unavailable, the theme control still works for that page visit.

Fonts come from the visitor's system. The hosting service receives requests for pages and assets. Following an external link sends the visitor to that site's own privacy and security practices.

The current published version is supported. If the repository's **Security** tab offers **Report a vulnerability**, use it to report a vulnerability privately. Do not include credentials, personal information or sensitive exploit details in public issues.
