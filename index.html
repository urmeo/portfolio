02 / Wearable sensing

CalmSense

Stress recognition from wearable signals, evaluated on participants held out from training.

  • WESAD: 15 subjects, 58 saved features and leave-one-subject-out (LOSO) evaluation.
  • Random forest binary accuracy: 0.910, averaged across subjects.

WESAD · LOSO · SHAP · Calibration

Repository Recorded metrics Live demo

Evidence note: Historical benchmark; current code differs from the version behind these recorded metrics.

03 / Demand forecasting

PulseShift

Forecasting bike-share demand suppression using weather and air-quality data.

  • 26,288 panel hours. 2024 unweighted holdout: AUROC 0.936; expected calibration error (ECE) 0.044.
  • Sources: Open-Meteo/CAMS. Exclusions: heat index ≥103°F or AQI ≥150.

Demand · Weather · AQI · Logistic

Repository Source predictions Live demo

Evidence note: Individual activity and health benefits were not measured.

04 / Retrieval systems

NexusRAG

Search local documents and generate answers with source citations.

  • PDF, DOCX, Markdown and text files → LanceDB + BM25 retrieval → Ollama.
  • Retrieval can expand once with pseudo-relevance feedback (PRF) below 0.55 similarity. Natural-language inference (NLI) is optional.

RAG · LanceDB · BM25 · Ollama

Repository Recorded evaluations Watch demo

Evidence note: Citation indices are checked; generated-answer accuracy was not measured, and claims still need review.
